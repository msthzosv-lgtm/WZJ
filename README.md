# 俄罗斯方块（电脑版可双击运行）

这是一个纯前端单文件俄罗斯方块，不需要安装依赖。

## 最简单：直接双击运行（推荐）

仓库里提供了两个可直接双击的页面：

1. `双击运行.html`（启动页，双击后会自动进入游戏）
2. `index.html`（游戏主页面，也可以直接双击）

> 在 Windows / macOS / Linux 电脑上，只要默认浏览器可用，就能直接打开运行。

## 备用方式：本地静态服务

如果你更习惯 URL 访问，也可以：

```bash
python3 -m http.server 8000
```

然后打开：`http://127.0.0.1:8000/index.html`

## 键盘操作

- `←` / `→`：左右移动
- `↓`：加速下落
- `↑`：旋转
- `空格`：一键到底
- `P`：暂停 / 继续

## 鼠标/触屏操作

右侧提供按钮：左移、右移、旋转、下移、到底、暂停。

## 这次针对“电脑双击运行”做的改动

- 新增 `双击运行.html`，双击即可自动进入游戏。
- `canvas` 增加可聚焦能力（`tabindex`），并在启动/重开时自动聚焦，减少“按键没反应”的情况。
- 点击游戏画布后也会重新聚焦，保证键盘操作更稳定。
