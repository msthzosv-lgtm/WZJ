# 贪吃蛇（网页版）

这是一个可直接在网页中运行的贪吃蛇小游戏：
- 吃到红色豆豆会加分并让蛇身变长；
- 分数越高，移动速度会逐步提升。

## 运行方式

### 方式 1：直接双击
直接用浏览器打开 `index.html` 即可。

### 方式 2：本地静态服务（推荐）
```bash
python3 -m http.server 8000
```
然后访问：`http://127.0.0.1:8000/index.html`

## 操作说明
- `↑` / `↓` / `←` / `→`：控制方向
- `P`：暂停/继续
- `R`：重新开始

页面右侧也提供了按钮，触屏设备可直接点击游玩。
